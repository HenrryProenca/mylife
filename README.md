# MyLife

Suíte pessoal de organização de vida. O **módulo Financeiro** é o primeiro.

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS
- Supabase (Auth + Postgres + RLS)
- TanStack Query
- React Router v6

## Pré-requisitos

- Node.js 20+
- Conta no Supabase
